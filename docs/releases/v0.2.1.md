# clink-integ-cli v0.2.1 security candidate

Status: source and offline-bundle review candidate only. This work does not publish npm artifacts, create or move a tag, create a GitHub Release, merge the Skill PR, or access a real Clink merchant or production resource.

## Security fixes

- API paths are resolved relative to the configured Clink API base and cannot override its origin or escape its base pathname. Real requests, dry-run output, and curl previews share the same validated URL.
- Generated Next.js, Express, and FastAPI public checkout routes select server-authoritative prices through a `priceKey` allowlist. They default to a server-configured registered Price; inline pricing is explicit opt-in, and client-selected quantity is disabled unless the chosen inline SKU enables a bounded 1-10 range. Browser-supplied amounts, inline price data, product/price IDs, merchant references, redirect URLs, and payment settings cannot override the server configuration. Subscription starters use the same boundary through a server-side `planKey`. Trusted local CLI checkout and subscription commands retain their existing capabilities.
- CLI profile and signing-secret env files are written atomically as private files. On POSIX, new and existing targets are forced to mode `0600`, including rollback restoration.
- Generated webhook handlers reject malformed, stale, and far-future signature timestamps with a 300-second tolerance before parsing the raw body. The timestamp check does not replace durable `event.id` deduplication within the accepted window.

## Compatibility

- `clink checkout`, catalog import, webhook fixtures, smoke tests, Merchant Webhook contracts, event presets, and endpoint ensure semantics are unchanged.
- The generated public checkout starter request contract intentionally changes from client-supplied payment fields to a server-side `priceKey` allowlist.
- The existing `v0.2.0` tag is not moved or replaced. The package and generated offline bundle identify this candidate as `0.2.1`.

## Verification

Run before review handoff:

```bash
npm ci
npm run verify
npm run pack:dry-run
npm audit
git diff --check
```

Install the resulting local tarball in a clean temporary directory and repeat the four security regressions against the installed CLI. Local fixtures, mock servers, and locally signed webhook requests are test evidence only; they are not real Clink sandbox events.
